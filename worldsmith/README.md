# Worldsmith

A free god sandbox that runs in your browser. Forge a world, fill it with life, watch
kingdoms rise — then flatten them with a meteor.

No install, no build step, no dependencies, no account, no cost. **Open `index.html` and
play.** It also works on a phone.

![the world](test/screenshots/1-world.png)

## Running it

```
# simplest: just open the file
xdg-open worldsmith/index.html      # or double-click it

# or serve it, if you prefer
npx serve worldsmith
```

It is a static page, so any static host works — GitHub Pages, Netlify, a USB stick.

## What's in it

**The world.** Procedural terrain with eight map shapes (continents, islands, archipelago,
pangaea, inland sea, highlands, lakelands, flat). Biomes come from real climate: latitude and
altitude set temperature, and a wind-driven humidity sweep creates rain shadows, so deserts
form in the lee of mountain ranges rather than at random. Rivers carve down from wet
highlands and pool in basins on the way.

**Living simulation.** Water is a real fluid — dig a canal and a lake drains through it, raise
the sea and coastlines flood. Fire burns actual fuel and runs downwind, uphill, and out when
it hits water or rain; burnt ground turns to ash and slowly regrows through succession. Lava
flows, cools into stone, and builds its own terrain. Seasons swing the temperature, ice creeps
down from the poles in winter, and erosion reshapes riverbeds over long sessions.

**Powers — 91 of them.** Terrain brushes (raise, lower, flatten, mountain, water, deep ocean,
drain, lava, and a dozen biome paints). Nature (rain, sun, frost, fertilise, wither, redirect
the wind). Disasters: meteor, meteor shower, lightning, thunderstorm, tornado, volcano,
earthquake, magma fissure, tsunami, nuke, acid rain, sandstorm, blizzard, plague, black hole,
demon rift, toxic cloud, ice age, heat wave, drought, deluge. Creature spawners for every
species. Kingdom tools — found villages, raze, advance the age, sow discord, impose peace.
Manipulation — grab and fling, heal, smite, bless, curse, mutate, tame, enrage, empower,
immortality.

**Life.** Four playable races (humans, elves, orcs, dwarves), nine animals, and six monsters
(dragon, demon, undead, wraith, kraken, sand worm) sharing a predator/prey food chain. They
eat, breed, inherit traits, catch and spread plague, mutate in radiation, and level up from
kills. Click anyone to read their name, age, traits and life story.

**Civilisation.** Villages found themselves on good ground, build huts, farms, mines, docks,
barracks, towers, temples, markets and walls, feed their people, and send out settlers.
Villages federate into kingdoms with generated names, colours and territory that hugs the
coastline. Kingdoms remember how they feel about each other, form alliances, declare wars over
contested borders, siege each other's buildings, and advance from the Stone Age to a Golden
Age.

## Controls

| Input                                  | Action                        |
| -------------------------------------- | ----------------------------- |
| Drag                                   | Use the selected power        |
| Right-drag, shift-drag, or two fingers | Pan                           |
| Wheel or pinch                         | Zoom                          |
| `W A S D` / arrows                     | Pan                           |
| `Space`                                | Pause / resume                |
| `1` `2` `3` `4`                        | Speed 1× / 2× / 4× / 8×       |
| `[` `]`                                | Brush size                    |
| `G` / `B`                              | Toggle grid / kingdom borders |
| `Esc`                                  | Clear selection               |
| Click a creature                       | Inspect it                    |

Save and load live under **Menu**, along with world settings, JSON export/import and a map
PNG export. Worlds save to browser storage; use file export for anything you want to keep.

## How it is built

Plain JavaScript and a canvas. No framework, no bundler, no npm install. Files are classic
`<script>` tags sharing one `WB` global, deliberately: ES modules are blocked by CORS on
`file://`, which would break opening the page directly.

All the art is generated by code at startup — sprites are pixel-string tables rasterised into
one atlas, toolbar icons are drawn with canvas primitives, and sound is synthesised with
WebAudio. Nothing is loaded from disk or the network, so the whole game is a few hundred KB of
source.

The world is structure-of-arrays over typed arrays, one flat array per field. Fire, water,
lava and acid run on active sets, so a still ocean costs nothing and a wildfire only costs its
own burning front. Slow whole-map systems (climate, vegetation) sweep a few rows per tick.
Unit AI is round-robin under a per-tick budget, and villagers path home with one BFS field per
village instead of per-unit A\*. Rendering blits a one-pixel-per-tile `ImageData` scaled with
smoothing off, rebuilding only the 32×32 chunks that changed.

That budget holds up: **~1,900 simulation ticks/sec at 384×256 with 1,300 units**, about
0.5 ms per tick, measured by the test below.

```
worldsmith/
  index.html  styles.css
  src/
    core/    rng noise grid camera loop events
    world/   terrain worldgen water fire lava climate
    gfx/     atlas icons render particles minimap
    life/    species names units
    powers/  blast effects registry
    civ/     buildings kingdoms villages civai
    io/      audio save
    ui/      ui
    main.js  boot.js
  test/smoke.mjs
```

## Tests

```
npm i -D playwright        # if you don't already have it
node worldsmith/test/smoke.mjs
node worldsmith/test/smoke.mjs --screenshots
```

The suite loads the game over `file://` (which is also how it proves the no-server claim),
then checks generation sanity, 2,000 ticks without NaN, water conservation in the fluid sim,
that all 91 powers apply without throwing, that the big disasters measurably change the world,
sustained tick rate, a save/load round-trip, and that the layout survives a 420px-wide screen.
